# N21 训练范围、任务隔离与环境

问题：当前harness优化没有稳定SR收益，训练需独立数据边界及兼容Qwen3.5的环境。

方案：用户授权后扩展到规划诊断、轨迹生产及一次LoRA SFT；已有dev120按固定种子、十二类划分train60/calibration12/eval48。eval不进入本轮训练/选优，剩余95个未使用任务封存；共享生成器和历史暴露仍限制结论。

结果：ID、内容、精确query无交叠，数字归一化交叠0但不证明模板独立。90项运行链路测试通过。独立`.venv-sft`继承现有Torch2.9/PEFT0.21，单独安装Transformers5.18及固定依赖；原Conda/venv未改。小型混合Qwen3.5图验证目标位置、LoRA反向传播通过，不能替代真实四卡训练验证。

问题处理：服务器直连DNS不可用，既有代理可取元数据但wheel下载SSL失败；使用本机下载并核对PyPI SHA256，再scp到服务器独立环境安装。模型、任务数据不上传、不改上游。新增FLA0.5.2供GPU训练，保留安装收据。
