# N40 Verifier Feedback 与 Agentic RL 接口

问题：运行时验证信号尚未有稳定的 process reward 定义，直接接入 RL 会把 verifier 漂移和 task reward 混在一起。

方案：新增不可变 `RolloutFeedback` 和 `ProcessRewardWeights`，固定 task success、hard violation、semantic reject、超步数四项计分；新增 RL-A/RL-B/RL-C 配置，第一版明确冻结 verifier，只训练 actor。保留小 verifier、Self-Reflection 和最终 task reward 的独立对照门槛。

结果：反馈计分不依赖隐藏 evaluator 字段，且只统计实际 blocked audit；RL-A 保持 sparse task reward，RL-B/C 才加入确定性/语义过程惩罚；交替调度禁止越界和同轮更新 verifier。22项 N38–N40 专项测试通过，`compileall` 和 `scripts/check_project.py` 通过。当前只交付 Harness/消融接口和冻结配置，按本轮范围不启动 SFT/RL、不生成新 benchmark。
