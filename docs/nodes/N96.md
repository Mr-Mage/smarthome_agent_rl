# N96 进程中断恢复

问题：进程可能在动作已认领、外部调用尚未写回时退出；重启后直接重新调度会产生重复副作用。

方案：`RuntimeStore.recover_inflight()` 在运行时入口打开数据库时执行。CLAIMED 统一转为 UNKNOWN 并写恢复事件；REGISTERING 保持待核对状态。恢复只更新本地记录，不调用设备；后续必须通过既有 reconcile 路径处理。

结果：重启不会盲目重放动作，任务回到可核对状态，恢复事件可审计。原子认领和现有 UNKNOWN 语义保持不变。

验收：`tests/test_restart_recovery.py` 与原 Scheduler 测试通过；实现提交见 Git。
