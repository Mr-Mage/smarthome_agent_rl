# N2 官方评测接入

问题：旧 dev runner 会改写初始状态，不能用于官方 benchmark；新 Gateway 默认温度误覆盖 actor 参数，实时环境也使后续观测不同。

方案：冻结官方 120 dev/192 final（12 类均衡且不重叠），24 项 smoke 只取 dev；接入原 run_single_config，保留 reset、时间、required actions 和三票 judge。进程内替换 agent 工厂，不改上游。校验实际后端请求，固定请求单独验证传输。

结果：两路共 6 对固定请求的参数、文本和 token IDs 一致；24 项 B0 smoke 完整通过工程核验，成功 9/24。任务失败保留，非基础设施失败；此结果不是主实验成绩。39 项测试通过。

证据：`configs/benchmark-mvp/`；本机 `outputs/harness-mvp/N2/`；远端 `runs/harness-mvp/align-v3/` 与 `smoke-b0/`。前两次对齐诊断保留。提交：`git log -- docs/nodes/N2.md`。
