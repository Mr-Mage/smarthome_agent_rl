# N8 并发性能验收（完整复跑中）

问题：两路串行推理利用率低；扩并发后，官方工作流评测形成长尾。

方案：独立模拟器槽共享 actor，保持任务配对；测 2–64 请求并发、前缀缓存与 CUDA Graph，再比较 32/64 槽及工作流优先调度。保持权重、生成参数、步数、模拟器动力学和 judge 规则；模型身份校验与 dev 并行。

结果：回放输出吞吐 87.98 → 2,468.12 tokens/s，无请求错误。32 槽工作流优先试跑 120 次用时 230.86 秒，原顺序 271.56 秒；64 槽为 282.23 秒。选 32 槽，全量推算 43.86 分钟；各试跑均通过独立核验。

修复：用户要求实施计划后，应用最小参数类型检查，未转换参数；SimuHome 独立提交 `e202971`，补丁见 `patches/SimuHome/command-args.patch`，依赖锁记录原任务快照与新运行时。实际重放 HTTP 500 → 200。
