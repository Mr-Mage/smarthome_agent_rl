# N98 上下文数据契约

问题：历史观测、当前状态、动作回执和模型错误容易混进同一段上下文，过期事实可能被当成当前前置条件。

方案：新增 `ContextPolicy`。目标、版本、状态和约束始终保留；当前事实优先于历史事实；回执与错误保留来源；过期事实单列并标记 stale。超预算按历史事实、回执、错误、当前事实的顺序裁剪，记录 omitted 数量，不做语义摘要。

结果：上下文选择可复现、可解释，保留状态来源和失败证据；模型是否使用该上下文仍由显式 runtime 配置决定，不改变冻结 G。

验收：`tests/test_context_policy.py` 通过；`RuntimeBoundary.context` 提供统一入口。
