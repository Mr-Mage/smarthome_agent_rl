# N39 Semantic Verification 与 Self-Reflection 基线

问题：合法工具调用仍可能选错房间/设备、违背目标或重复抵消前序动作；需要先证明语义验证问题，再比较 Actor 自反思与独立 verifier。

方案：新增 public-only `VerificationContext`、四维 decision（`correct_target / goal_consistent / trajectory_consistent / safe_to_execute`）、`YES/NO/UNCERTAIN` 标签、置信度门控和结构化反馈。新增无 CoT 的 `SelfReflectionVerifier`，严格解析四字段 JSON。数据脚本只从成功公开轨迹构造正例，并生成错误设备、相反动作和重复动作 hard negative；不读取 evaluator/judge 隐藏信息。

结果：规则 verifier 可识别 wrong target、goal conflict、trajectory conflict；不确定样本可升级到 reflection。新增置信度门控：低置信度拒绝降为 `UNCERTAIN`，高置信度拒绝才可阻断；反馈包含失败维度、公开证据和 repair hint；`VerificationContext` 拒绝 evaluator/judge/official score 等隐藏字段。9项语义、reflection 和数据构造测试通过。按当前范围未启动在线模型对照，也未生成新 benchmark；规则标签不作为最终语义真值。
