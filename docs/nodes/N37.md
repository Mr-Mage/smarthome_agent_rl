# N37 官方600任务全量验收

问题：项目只有覆盖十二类的子集结果，缺少同一冻结版本的完整benchmark成绩。

方案：用户于2026-10-06授权全量验收，包括此前封存95任务。冻结当前官方600任务（十二类各50）、原Qwen3.5-9B的B0/G×seed42共1,200次；生成参数、20步上限及G策略沿用N36。四H100各单卡actor、64槽，A800常驻judge。运行器使用dev操作阶段，但本轮不开发/选优；全量含已暴露任务，不作为独立留出收益。

验收：核对1,200条完整轨迹、任务SHA、模型/参数/配对身份；汇总总体/十二类SR、非法执行、未完成、actor/judge tokens、Agent/episode/评测延迟及含启动/失败/清理成本。普通失败均保留；基础设施故障使整阶段无效，仅允许一次同配置整轮重跑，重复故障停止。无结果后的调参、任务挑选、训练或上游/环境变更。

结果：1,200次/12,391阶段文件核验通过；B0/G成功197/600、231/600（32.83%/38.50%），非法325→70（-78.46%），未完成5→8，actor tokens/任务+5.49%。全量配对差+5.67pp、95% CI[+2.17,+9.00]pp、p=0.00245；含历史暴露，不替代N13独立留出结论，不重新选优。QT4-2不可行仍0/50，QT4-3低。8,402次actor与2,022次judge请求身份、参数与配对一致；150测试149通过/1环境跳过。

成本：含启动与清理总耗时1320.23秒（约22分钟），启动298.74秒，H100预留5280.91 GPU秒。含探针actor/judge tokens为53,593,960/4,321,299，缺usage请求0；GPU采样均值69.85%，KV峰值8.77%，抢占/监控错误0。队列峰值actor/judge等待1/14；瞬时队列不等于持续瓶颈。额外参数/资源复核30.43秒；A800共享分摊及准备、归档CPU未完整计量。首次环境激活切换目录导致driver未进入即退出，零推理，日志保留。
