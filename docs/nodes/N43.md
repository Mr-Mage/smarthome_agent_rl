# N43 持久 Task Session

问题：对话结束或进程重启后不能靠 LLM 聊天历史管理用户目标，任务修订也不能使旧定时任务继续执行。

方案：SQLite 保存 Task、Workflow、Job 和不可改写的 Tool Trace；TaskSession 保留用户、原始会话、版本、设备、目标后置条件和证据。修订采用版本比较与事务；取消旧本地计划，设备原生计划须先确认取消。

结果：5项测试通过：跨会话/重启找回同一任务、并发修订仅一方成功、用户隔离、全设备目标验证、调用证据不可覆盖。任务完成仅由全部公开后置条件决定；本轮为单元验证，未产生公开 benchmark 收益。

证据：`execution/store.py`、`execution/tasks.py`、`tests/test_task_runtime.py`、`runs/task-runtime/n43-v1/`。提交见 `git log -- docs/nodes/N43.md`。
