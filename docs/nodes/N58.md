# N58 定时验证的观测时间

问题：Scheduler错过窗口后可通过reconcile用当前状态宣称早前任务完成；tick也只检查调度时间，未检查读回的观测时间。

方案：PostconditionResult增加可选observed_at，来自可信适配器/模拟器时钟。定时结果必须在原target_time至target_time+tolerance窗口；tick拒绝调用前的旧快照，reconcile显式传当前适配器时间并拒绝未来快照。缺失/越界保留UNKNOWN和候选证据，不重放动作。非定时Mutation不要求时间字段。

结果：晚到当前快照不再证明早前成功；已保留的窗口内观测可恢复，未来、缺失、NaN及布尔时间均拒绝。整Task验证保留已确认失败的定时Job，不让后续匹配状态覆盖失败。最终服务器91项累计专项通过，全量260项259通过/1环境跳过；调用预算/默认G不变。时间来自适配器，不保证外部设备时钟准确；仅工程验收，未接入官方Scheduler消融，无新增Task SR。
