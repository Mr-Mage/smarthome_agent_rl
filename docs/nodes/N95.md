# N95 运行时入口收敛

问题：Task、Trace、Scheduler 可以被调用方分别构造，容易形成策略不一致的第二套状态机。

方案：新增 `RuntimeBoundary.open` 作为持久运行时组合根，统一创建 SQLite Store、TaskManager、ToolTrace 和 Scheduler；默认禁止未知变更自动重放，并提供只读 health 快照。官方 benchmark 入口不改。

结果：入口、状态持久化和调度器连接关系可由测试直接验证；默认 G 与历史评测不受影响。

验收：`tests/test_runtime_boundary.py` 通过；配置为 `configs/runtime-boundary.json`。实现提交见 Git。

后续：在该入口上补进程中断恢复、重试预算和上下文策略，逐节点验收。
