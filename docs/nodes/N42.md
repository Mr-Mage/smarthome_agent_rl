# N42 执行模型拆分

问题：原 ActionLedger 对 Query、普通 Mutation、异步 Workflow 使用同一生命周期，回执也不能证明设备目标状态。

方案：新建 `execution/`：Tool Trace 记录全部实际调用；Mutation 按 Contract 校验、执行一次、读回、判断后置条件；Workflow 单独维护 CREATED/SCHEDULED/ACTIVE/VERIFIED_SUCCESS/FAILED/CANCELLED。新 Runtime 显式启用，N37 对照不改。

结果：11项测试通过。200+错误读回判 VERIFIED_FAILURE；timeout+正确读回判 VERIFIED_SUCCESS，mutation 仅发一次；缺读回判 UNVERIFIED；非法参数和未知前置条件不执行。Query 无生命周期，Workflow 不能凭注册回执完成。新增读回调用计入 Tool Trace。尚未获得在线收益。

证据：`configs/execution-runtime.json`、`tests/test_execution_runtime.py`、`runs/task-runtime/n42-v1/`。提交见 `git log -- docs/nodes/N42.md`。
