# N44 声明式 SimuHome 契约

问题：Guard 的 cluster 分支与设备约束分散，缺少后置条件和验证方法；同名 command 在不同 endpoint 也不能混淆。

方案：公开结构、已有 AST 命令签名/供电规则编译为统一 Contract；已知 range/postcondition 迁入 `device-contract-rules.json`。函数键含 tool/endpoint/cluster；只读属性、缺签名、未覆盖前置条件显式返回，未来状态不按当前状态臆测。

结果：新增四项契约适配测试通过，连同 N38/N42 共15项。新灯具读回、参数范围/schema、不存在 endpoint、只读和未知签名均覆盖。当前覆盖部分源代码已验证规则；未知规则仍保留 uncovered，未宣称完全替换旧 Guard。

证据：`configs/device-contract-rules.json`、`execution/simuhome_contract.py`、`tests/test_runtime_contract_adapter.py`、`scripts/check_task_runtime.py`。提交见 `git log -- docs/nodes/N44.md`。
