# N11 Context v2

问题：旧账本常比原历史更长；缩短字符不等于减少模型输入成本。

方案：完整历史保留在磁盘，prompt发送最新公开事实、来源/失效标记、错误、收据及最近两对消息。辅助查询不误删；目录变更标失效；原指令和工具定义保留。使用模型chat tokenizer判定是否更短，统计tokenizer调用成本。

结果：120任务×3种子，GC2启用1,485/2,658轮（55.87%，旧GC 13.82%）；tokenizer调用2,970次、累计151.76秒。GC2成功116/360（G 136），actor tokens/任务45,056（G 43,614，增加3.30%），未过成功率与节省10%成本门槛，候选不启用Context v2。压缩启用率不能代替完整轨迹成本收益。

证据：`runs/harness-v2/primary-v2/modules/report.json`、`module-audit/audit.json`；67项测试通过。记录提交见`git log -- docs/nodes/N11.md`。
