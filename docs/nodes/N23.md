# N23 真实轨迹与SFT数据冻结

问题：训练需正确工具决策及真实观测，不能把模型自述或judge通过直接当成逐步正确标签。

方案：仅train60任务；回收四个完整历史阶段中的G轨迹，35B教师真实运行60任务×两种子。核验来源哈希，剔除失败、错误动作和含状态变更的不可行轨迹；同任务最多两条去重轨迹。工具参数保持原样，thought改为简短工具意图，只监督当前assistant目标。

结果：教师45/120官方成功，全部1,422文件核验。最终35个独立训练任务、65条来源轨迹、361个目标（教师101）；输入2,061,202 tokens、监督21,718 tokens，最长11,478。五份超长样本完整排除，不截断标签。达到冻结≥24任务、≥120目标及F/IF覆盖门槛；独立复核任务原文、来源SHA、动作参数和真实token掩码通过。

抽检：case48正确注册+22/+30/+51分钟；错误`setpoint`目标被剔除，正确`target_temperature`恢复动作保留。信息查询与缺设备拒绝案例均有真实工具依据。覆盖9/12类，三个工作流不可行类无标签；teacher/judge共用35B，成功筛选仍不保证完整语义正确。短thought可能直接降低输出成本，不能据此证明规划改善。
