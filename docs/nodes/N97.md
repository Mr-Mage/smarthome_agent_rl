# N97 异常与重试预算收口

问题：查询重试、动作修正和未知变更核对容易嵌套，原有网络层重试也没有统一记录。

方案：新增 `RetryBudget` 三类独立计数；`ToolTrace.call_read` 只对明确的超时、连接失败和暂时性 HTTP 状态重试。变更仍使用 `call`，不会自动重放；UNKNOWN 走 Scheduler reconcile，修正参数由上层新计划承担。

结果：每次尝试仍进入 Trace，预算耗尽原因可审计；变更调用没有重试入口，避免重复副作用。默认 G 不启用新重试策略，避免改变历史基线。

验收：`tests/test_retry_budget.py` 通过；预算配置与运行时入口保持显式 opt-in。
