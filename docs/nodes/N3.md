# N3 Guard 验收

问题：外层 JSON 合法仍会出现命令参数大小写、只读属性、能力缺失和电源/温控前置条件错误。

方案：从公开 tool/API schema、cluster 签名和设备源码提取规则；未知约束交给模拟器。拦截后返回结构化错误，由模型重新规划，不改参数、不代执行修复。只把真实调用传给 evaluator。

结果：24 项 B0/G 配对，各成功 10/24；非法提议 14→19，进入执行器的非法调用 14→1。G 增加 44 次查询、actor tokens +16.4%，尚无总体成功收益。调光/空调/风扇的 84 个公开接口差分用例无误拦截；覆盖范围之外不作保证。
