# 实验报表

持续记录论文参照、Qwen3.5-9B 基线及各节点实验；新结果产出即更新，历史结果保留。最新完整实验：N6 dev 600 次、final 768 次，均已验收。

## 指标与口径

- **成功率 SR**：成功任务数 / 全部任务数；未完成任务仍计失败。当前项目沿用官方 evaluator；QT1 与不可行请求使用本地 Qwen3.6-35B-A3B judge，同一模型的三个种子投票。
- **Actor tokens/任务**：全部成功和失败任务的模型输入 + 输出 tokens 均值，不含 judge 或检索 tokens。**非法执行**：实际调用工具后返回非法动作错误的次数，排除解析/schema 拒绝和辅助查询。**额外查询**：harness 为 Guard/验证增加的查询次数。两项调用计数均为整组总量。
- **F / IF**：可行 / 不可行请求；**ΔSR**：相对同轮 B0 的成功率差，单位为百分点。95% CI 跨 0 或 Holm p≥0.05 时不宣称显著提升。**—**：未报告或旧口径未重算。
- 论文为原始 600 任务（每类 50）；项目为更新后的仓库快照 `83d2883`，dev 120（每类 10）、final 192（每类 16），smoke 24 为 dev 子集。P0/P1 使用另建的 16 个开发任务；这些口径分别记录，不跨表计算提升。
