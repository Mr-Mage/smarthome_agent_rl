## 已完成的对齐

- 单卡主入口 `run-single-h100.sh` 直接运行本项目 B0，支持单一 ReAct 配置；不再默认启动原 CLI 和 harness 消融。
- 复用外部 ReAct 循环、提示词和完整工具，新增本项目 `BaselineAgent` 的 Lightning 入口；不修改 SimuHome。
- 显式配置生成参数，并核对它们通过 SDK、Lightning Gateway 到达真实模型请求；保留模型响应、usage 和 token IDs。参数适配只改变声明的生成设置，不修改工具、消息或输出格式，不修复模型回答。
- 保存 `run_protocol.json`：B0 身份、实际模型用途、生成设置、调用预算、seed、任务列表及配置/任务哈希。独立 verifier 检查每个任务恰好运行一次，全部结果与冻结配置一致。
- 对齐任务失败语义：未完成目标、达到步数上限或连续非法输出可以成为带失败 reward 的有效轨迹；网络、模型服务或事件存储异常仍让 worker 报错。worker 正常完成不代表任务成功。
- 9B 必须有对应 repo/revision 的完整校验标记才能启动。实际测试证明部分下载会在模型服务启动前停止，且不会留下空运行目录。

## 冻结的 B0 配置

| 项目 | 当前设置 |
|---|---|
| B0 | B0-ReAct-v1；原 ReAct 循环，显式 finish，最多 20 次调用 |
| 模型 | 正式目标 Qwen3.5-9B；当前工程回退模型 Qwen2.5-1.5B-Instruct |
| 输出预算 | 每次最多 2048 tokens，服务上下文 32768 |
| 生成 | temperature=0.7、top_p=0.8、top_k=20、presence_penalty=1.5、min_p=0、repetition_penalty=1 |
| Thinking | API 明确请求 enable_thinking=false；保留 ReAct 输出的 thought 字段。9B 的实际行为待模型就绪后验证 |
| Seed | 模型请求 42，推理引擎 0；记录实际请求，不据此承诺逐 token 完全相同 |
| 任务 | 现有 16 项独立 dev：跨房间灯控、灯组、调光、风扇，各 4 项；参考执行计划不进入模型输入 |
| 成功 | 实际环境目标全部满足、合法 finish 且 agent 正常结束；goal_success 另行记录 |
| Reward | success + progress − invalid − 调用/token 成本；全部由实际状态和真实 usage 核验 |

生成设置参考 [官方 Qwen3.5-9B 模型卡](https://huggingface.co/Qwen/Qwen3.5-9B) 的 non-thinking 示例。上下文和输出预算是本项目的固定实验选择。与历史 temperature=0 的运行配置不同，不能把调用数差异归因于 harness 改进。
