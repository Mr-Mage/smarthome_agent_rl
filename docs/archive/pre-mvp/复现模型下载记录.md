## 传输方式与恢复

H100 外网域名解析失败，因此本机 relay 通过 `hf-mirror.com` 流式转发固定官方 revision 的文件，远端仍以官方哈希验证。Relay 仅绑定 127.0.0.1:18099，仅允许 manifest 内路径，支持 Range，核对返回的大小和范围，不保存本地权重，不向远端暴露 CDN 签名跳转链接。H100 loopback 17999 经 SSH 转发到本机 18099；真实远端小文件请求与大权重传输均已成功。

用户 SSH 配置自带的另一 RemoteForward 与已有连接冲突。任务使用只保留已解析连接字段的临时 SSH 配置，建立独立转发，未修改用户配置。该临时连接配置不进入交付包，也不输出其中内容。

本机和转发进程需要保持运行。若电脑关闭、连接中断，下载会重试；恢复 relay/转发后可从 `.partial` 续传。已校验的完整文件跳过；损坏完整文件不自动覆盖。
