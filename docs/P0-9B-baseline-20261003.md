## 调光失败证据

四项调光均为目标未满足时合法 finish，实际设备状态支持失败结论。主要问题包括：

1. dimmer-0/1/2 把 MoveToLevel 的参数写为 `level`、`transitionTime`，或拼成 `transtionTime` / `timeRemaining`。固定 SimuHome 实现要求 `Level`、`TransitionTime` 等准确参数名；API 返回 400。
2. dimmer-3 把 execute_command 的内层 args 写成 JSON 字符串，例如 `"args": "{}"`，而不是对象；普通 On 命令也因参数类型错误被拒绝。
3. 错误后尝试直接写只读 CurrentLevel 或 OnOff，继续收到 400，并重复相同非法动作。模型没有可靠地纠正设备命令语义。

fan-3 还有一次 FanMode="LOW" 被拒绝，后续恢复并完成目标。它证明这次轨迹恢复成功，不证明普遍的恢复能力。

压缩后的失败审计见 failure_audit.json；完整轨迹、观测和状态在每个 episode。没有更改模拟器、放宽 verifier、补齐模型参数或替换失败样本。
