# SFT试验执行计划

目标：验证9B的推理模式与经工具验证的轨迹SFT能否改善规划；G保持不变，不做RL。

| 节点 | 实施与验收 |
|---|---|
| N21 | 从已有dev120按十二类固定随机划分train60/calibration12/eval48；隔离ID、内容/query哈希并记录模板风险。检查模型、训练环境及上游身份，封存剩余95任务。 |
| N22 | 在train+calibration72上对比G/原生thinking，同输出2048、20步预算；先24任务smoke，再72×两臂×三种子。核验实际reasoning字段、成功率、非法执行、tokens、延迟；不使用eval选模式。 |
| N23 | 回收有效历史G成功轨迹，仅train任务；教师35B在train60各两个固定种子真实运行。只保留官方成功、无基础设施错误的正确动作目标；错误动作不作为标签，观测作输入。同任务最多两条去重轨迹。记录每类覆盖、失败、tokens、抽检及同模型teacher/judge偏差。 |
| N24 | 数据准入后进行一次LoRA SFT：rank16、alpha32、dropout0.05、LR1e-4、1 epoch、seed42，4卡DDP、每卡batch1、累积4，完整样本长度≤16384，超长不截断标签而排除。只训练当前assistant目标，不训练用户/观测/历史回复或隐藏reasoning。保存adapter、loss、真实GPU与耗时，合并独立模型。 |
| N25 | 冻结模型后，在eval48上同轮原模型+G/SFT+G，种子42/43/44；报告任务聚类CI、分类SR、非法执行、tokens及Agent延迟。SR不降、非法执行不增、tokens≤1.10才保留开发候选；不宣称48个任务能证明5pp显著提升。归档全部失败与成本。 |

N23数据准入：至少24个独立训练任务、120个正确动作目标，覆盖可行与不可行；无跨split泄漏，无空标签，样本来源与哈希可追溯。仅成功筛选不保证语义正确；抽检已有训练内容，不查看封存任务。不足则结束数据节点并明确训练未准入，不复制样本补门槛。

训练前质量规则：不把被拦截、执行错误或截断动作作为标签；保守排除包含状态变更的不可行轨迹，可能同时排除合法的部分履约。原thought替换为简短工具意图，原工具与参数保持不变；因此输出成本下降不能单独解释为规划改善。保留原始轨迹和排除计数。

所有评测均来自原官方任务，原时钟/evaluator不变。eval48虽未进入本轮训练/选优，历史已用于harness开发，因此只称任务隔离的开发诊断，不称独立正式留出集。共享生成器的模板独立性无法证明。教师使用常驻A800服务，评测judge同模型造成筛选偏差，不能用教师通过率证明训练收益。

推理：四个单卡actor，共64槽；各对比臂同task×seed固定同actor。训练期间停止H100 actor，4卡用于DDP；teacher与judge常驻服务不重启。运行数据在runs，临时文件在work，各节点一份记录，结果产出追加实验报表。
